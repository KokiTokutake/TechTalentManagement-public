## 1. 背景・目的（Why）

### 1.1 解決する問題

現状、人材開発委員会（MDC）の事前資料は上長が個別にExcelや資料を作成して提出しており、フォーマットが統一されておらず審議に時間がかかる。タレントの複数期にわたる情報（スキル・評価・面談履歴）が一元化されていない。

### 1.2 ビジネス価値

- タレントプロファイルを自動生成することで、MDC事前準備の工数を削減する
- 標準フォーマットにより委員会審議の効率と質が向上する
- リクルート社のMDC事前シート（8〜10ページ）を参考に、本システムに最適化した構成とする

### 1.3 対象ユーザー

| ユーザー | 権限 |
|---------|------|
| 上長 | 配下タレントのプロファイル閲覧・育成コメント入力 |
| 管理職 | チーム全員のプロファイル閲覧 |
| 管理者（人事評価チーム）/ Senior / Executive | 全タレントのプロファイル閲覧・PDF出力・MDC紐付け |

## 2. 要件（What）

### REQ-01: プロファイルの自動集約表示 【Must】

タレントIDを軸に、以下の情報を1画面に集約表示する：
- 基本情報（氏名・ロール・所属・入社年・年齢）
- 直近の9ボックス評価（パフォーマンス・ポテンシャル）
- Will-Can-Must（直近の考課期間）
- スキルサマリー（レベルの高い順 上位5件）
- 直近の面談記録サマリー（最新3件のタイトルと日付）
- MDC決定事項の履歴（過去2回分）

### REQ-02: 上長育成コメントの入力 【Must】

上長が「現在の課題」「育成方針」「期待役割・ポジション（1〜3年後）」をテキストで入力できる。考課期間ごとに保存され、前期の内容を複製して編集できる。

### REQ-03: 重点管理フラグの表示と設定 【Must】

タレントが重点管理人物として指定されている場合、プロファイル上部に「重点管理」バッジを表示する。MDC委員がプロファイル画面から重点管理フラグを設定・解除できる（変更履歴を記録）。

### REQ-04: PDF出力（委員会配布資料） 【Should】

タレントプロファイルをPDF形式でエクスポートできる。1名あたりA4 1〜2ページ相当。ページフッターにエクスポート日時・機密区分を印字する。

### REQ-05: 複数タレントの一括閲覧 【Should】

MDCセッションに紐付いた対象タレントのプロファイルをスライド形式（カルーセル）で連続表示できる。

### REQ-06: スキル・評価推移グラフの埋め込み 【Could】

スキルレベルの推移（過去4期分）と9ボックス評価の推移を小型グラフとして埋め込む。

---

## 3. スコープ外（作らないこと）

- プロファイルの自動翻訳（日本語のみ対応）
- タレント本人によるプロファイルの直接編集（キャリアプランは別スペックで対応）
- AI/ML を使った育成提案の自動生成（将来の拡張として位置付ける）

## 4. 受入基準

### REQ-01: プロファイルの自動集約表示

**AC-01-01: 情報の集約表示**
- Given: タレントAに対して、直近の考課期間の9ボックス評価・Will-Can-Must・スキル評価・面談記録が存在する
- When: タレントAのプロファイル画面を開く
- Then: 基本情報・9ボックス評価・Will-Can-Must・スキルサマリー・面談サマリーが1画面に表示される（スクロール可）

**AC-01-02: データ未入力時の表示**
- Given: 新規タレントで9ボックス評価が未入力である
- When: タレントのプロファイル画面を開く
- Then: 9ボックス評価セクションに「未評価」と表示され、他のセクションは正常に表示される

**AC-01-03: 考課期間の切り替え**
- Given: タレントAが2024Q1と2024Q3の2期分のデータを持つ
- When: 期間セレクタで「2024Q1」を選択する
- Then: 2024Q1時点のWill-Can-Must・9ボックス評価が表示される

### REQ-02: 上長育成コメントの入力

**AC-02-01: コメントの保存**
- Given: 上長がタレントAのプロファイル画面で育成コメント欄を編集している
- When: 「現在の課題」「育成方針」「期待役割」を入力して「保存」をクリックする
- Then: コメントが考課期間と紐付いて保存される

**AC-02-02: 前期コメントの複製**
- Given: 前考課期間に育成コメントが入力済みである
- When: 新考課期間のコメント欄で「前期から複製」ボタンをクリックする
- Then: 前期のコメント内容が現在の入力欄にコピーされる（保存前の状態）

### REQ-03: 重点管理フラグ

**AC-03-01: フラグ表示**
- Given: タレントAが重点管理人物として登録されている
- When: タレントAのプロファイル画面を開く
- Then: 画面上部に「重点管理」バッジ（オレンジ色）が表示される

**AC-03-02: フラグの設定・解除**
- Given: MDC委員がタレントAのプロファイルを開いている
- When: 「重点管理に指定」ボタンをクリックして確認ダイアログで「確定」する
- Then: 重点管理フラグが設定され、変更日時・設定者がAuditLogに記録される

### REQ-04: PDF出力

**AC-04-01: PDF生成**
- Given: タレントAのプロファイルが表示されている
- When: 「PDF出力」ボタンをクリックする
- Then: A4フォーマットのPDFが生成されダウンロードされる（ファイル名: `profile-{talentName}-{YYYYMMDD}.pdf`）

**AC-04-02: 機密表示**
- Given: PDF出力が実行される
- When: PDFが生成される
- Then: フッターに「社外秘」「出力日時：YYYY-MM-DD HH:MM」が印字される

### REQ-05: 複数タレントの一括閲覧

**AC-05-01: スライド形式表示**
- Given: MDCセッションに対象タレントが5名登録されている
- When: セッション詳細画面から「プロファイルを確認」をクリックする
- Then: 5名のプロファイルがカルーセル形式で表示され、「次へ」「前へ」で切り替えられる

## 5. データモデル（概要）

```
TalentManagerComment {
  id: string (ULID)
  talentId: string → User.id
  managerId: string → User.id
  periodId: string → EvaluationPeriod.id
  currentChallenges: string | null (max: 2000)   # 現在の課題
  developmentPolicy: string | null (max: 2000)   # 育成方針
  expectedRole: string | null (max: 1000)        # 期待役割・ポジション
  createdAt: datetime
  updatedAt: datetime
}

KeyPersonFlag {
  talentId: string → User.id  (PK)
  isActive: boolean
  activatedAt: datetime | null
  activatedBy: string → User.id
  deactivatedAt: datetime | null
  deactivatedBy: string | null → User.id
  reason: string | null (max: 500)
}

# TalentProfile は集約ビュー（ビューモデル/読み取り専用）
# 実態は各エンティティ（NineBoxAssessment, Goal, Skill, OneOnOneMeeting 等）から取得
```

## 6. APIエンドポイント（概要）

```
GET  /api/talents/{talentId}/profile?periodId=        → プロファイル集約データ（Manager/Senior/MDC）
GET  /api/talents/{talentId}/profile/pdf?periodId=    → プロファイルPDF生成・ダウンロード

PUT  /api/talents/{talentId}/manager-comment?periodId= → 育成コメント保存（Manager）

PATCH /api/talents/{talentId}/key-person-flag          → 重点管理フラグ設定（MDC）

GET  /api/mdc-sessions/{sessionId}/profiles            → MDCセッション対象タレントのプロファイル一覧（MDC）
```

## 7. 非機能要件

| 項目 | 要件 |
|------|------|
| パフォーマンス | プロファイルの集約取得（全セクション）を3秒以内に返す |
| セキュリティ | タレントプロファイルはManager（配下のみ）・Senior・MDCのみアクセス可能。タレント本人は閲覧不可（キャリアプランは別途公開） |
| PDF品質 | A4縦・フォント埋め込み・印刷品質（解像度150dpi以上） |
| 監査ログ | 重点管理フラグの設定・解除・PDF出力はAuditLogに記録する |
