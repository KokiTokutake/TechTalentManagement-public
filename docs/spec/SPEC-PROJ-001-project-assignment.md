## 1. 背景・目的（Why）

### 1.1 課題・背景

現状システムには「誰がいつどのプロジェクトに参画し、どんな役割を担ったか」を記録する手段がない。

- **キャリアプランの裏付けデータが欠如**: タレントが「アーキテクトとして大型プロジェクトをリードした」と述べても、システム上で客観的に確認できない
- **スキル評価の根拠が弱い**: 上長がスキルを承認する際、実際の業務経験との照合ができない
- **アサイン判断に時間がかかる**: 次期プロジェクトへのアサインを検討する際、候補者の経験を個別に確認する必要がある
- **タレントプロファイルが不完全**: 委員会向けタレントプロファイル（SPEC-MDC-003）に業務経験の軸が欠けている

### 1.2 解決する価値

- エンジニアが自身の業務経験を記録・証明できる
- 上長がアサイン検討・育成計画の根拠データとして活用できる
- 委員会でタレントプロファイルと併せて業務経験を参照できる
- スキル承認時に実務経験との照合が可能になる

### 1.3 スコープ外（やらないこと）

- プロジェクト管理（WBS・工数・コスト）は対象外
- 採用管理・外部人材のアサインは対象外
- プロジェクトへの新規アサイン申請・承認ワークフローは対象外（記録のみ）
- スキルの自動採用（SPEC-SKILL-001 が参照している将来機能）は v2 検討

## 2. 要件（What）

### 2.1 機能要件

#### ユーザーストーリー

```
As a タレント（エンジニア）,
I want to 自分の参画プロジェクト・役割・期間を記録したい,
So that キャリアプランや評価面談の際に業務経験の裏付けとして使える。

As a 上長（Manager）,
I want to 部下のプロジェクト履歴を一覧で参照したい,
So that アサイン検討・スキル承認・育成計画の根拠データとして活用できる。

As a Senior / Executive,
I want to タレントプロファイルにプロジェクト履歴を組み込みたい,
So that 委員会審議の際に業務経験を含めた総合評価ができる。
```

| データ保持 | 評価データに準じ 7年保持（Constitution.md 2.3） |

## 6. 受入基準

### REQ-01: プロジェクト履歴登録

**AC-01-01: プロジェクトの登録**
- Given: タレントがプロジェクト履歴ページを開いている
- When: プロジェクト名・役割・開始日を入力して保存する
- Then: プロジェクトが一覧の先頭に追加される

**AC-01-02: プロジェクトの編集**
- Given: 既存のプロジェクト履歴が1件ある
- When: プロジェクト名を変更して保存する
- Then: 一覧の表示名が更新される

**AC-01-03: プロジェクトの削除**
- Given: 既存のプロジェクト履歴が1件ある
- When: 削除ボタンを押して確認する
- Then: 一覧からプロジェクトが消える

### REQ-02: データ記録

**AC-02-01: 参画中プロジェクト（EndDate なし）の登録**
- Given: タレントがプロジェクト追加ダイアログを開いている
- When: 終了日を空欄のまま保存する
- Then: 一覧に「参画中」ラベルとともに表示される

**AC-02-02: 終了済みプロジェクトの登録**
- Given: タレントがプロジェクト追加ダイアログを開いている
- When: 開始日・終了日を両方入力して保存する
- Then: 一覧に期間（開始〜終了）が表示される

### REQ-03: 使用技術の紐付け

**AC-03-01: スキルアイテムの紐付け**
- Given: プロジェクト追加ダイアログが開いている
- When: 使用技術として「Java」「Spring Boot」を選択して保存する
- Then: プロジェクト詳細に選択したスキルが表示される

### REQ-04: 上長参照

**AC-04-01: 上長がタレントのプロジェクト履歴を参照できる**
- Given: 上長が部下のタレントプロファイル画面を開いている
- When: プロジェクト履歴セクションを確認する
- Then: タレントが登録した全プロジェクト履歴が表示される

### REQ-05: 表示順

**AC-05-01: 一覧が期間の新しい順で表示される**
- Given: 3件のプロジェクト履歴が異なる開始日で登録されている
- When: プロジェクト履歴ページを開く
- Then: 開始日の新しい順（降順）で表示される。参画中（EndDate=null）は先頭に固定

### REQ-08: 上長コメント

**AC-08-01: 上長がコメントを追加できる**
- Given: 上長がタレントのプロジェクト詳細を参照している
- When: コメントを入力して保存する
- Then: コメントがプロジェクト詳細に表示される
