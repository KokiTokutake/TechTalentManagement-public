## 3. エンドポイント詳細

### `GET /api/v1/[resource]`

**概要**: [このエンドポイントの目的]

**リクエスト**

| パラメータ | 種別 | 型 | 必須 | 説明 |
|-----------|------|-----|------|------|
| `page` | query | integer | No | ページ番号（デフォルト: 1）|
| `limit` | query | integer | No | 取得件数（デフォルト: 20、最大: 100）|

**レスポンス**

```json
{
  "data": [
    {
      "id": "string",
      "name": "string",
      "created_at": "ISO8601"
    }
  ],
  "pagination": {
    "page": 1,
    "limit": 20,
    "total": 100
  }
}
```

| ステータスコード | 状況 |
|----------------|------|
| 200 | 成功 |
| 401 | 認証エラー |
| 403 | 権限エラー |
| 500 | サーバーエラー |

**概要**: [このエンドポイントの目的]

**リクエストボディ**

```json
{
  "name": "string",       // 必須: [説明]
```

| フィールド | 型 | 必須 | 制約 | 説明 |
|-----------|-----|------|------|------|
| `name` | string | Yes | 1〜100文字 | [説明] |
| `description` | string | No | 最大500文字 | [説明] |


## 5. 受入基準

- [ ] 正常系: 各エンドポイントが期待するレスポンスを返す
- [ ] 異常系: 不正なリクエストに対して適切なエラーコードを返す

- [ ] 認可: 権限外リソースへのアクセスに 403 を返す
