## 1. 背景・目的（Why）

### 1.1 解決する問題

一般に、上長とタレントの1on1面談は個人メモや非公式チャットで記録されがちで、人材開発委員会や考課での参照が困難である。面談の継続性（前回の宿題・課題の追跡）も担保されていない。

### 1.2 ビジネス価値

- 面談内容を構造化して記録することで、人材開発委員会の審議資料として活用できる
- 宿題・アクションアイテムの追跡により、タレントの成長支援の実効性が上がる
- リクルート社の定期1on1（月次・四半期）に倣い、Will-Can-Must面談と連動させることで考課サイクルを強化する

### 1.3 対象ユーザー

| ユーザー | 権限 |
|---------|------|
| タレント（一般エンジニア） | 自分の面談記録を閲覧（編集不可） |
| 上長 | 配下タレントの面談記録を作成・編集・閲覧 |
| 管理職 | 配下チーム全員の面談記録を閲覧 |
| 管理者（人事評価チーム） | 全タレントの面談記録を閲覧 |

## 2. 要件（What）

### REQ-01: 1on1記録の作成 【Must】

上長がタレントとの1on1面談記録を作成できる。記録には実施日・形式・面談メモ（Will-Can-Must各軸・近況・宿題）を入力する。

### REQ-02: 宿題（アクションアイテム）管理 【Must】

面談ごとに宿題を登録し、次回面談時に完了/未完了を確認できる。未完了の宿題は新規面談作成時に自動表示される。

### REQ-03: 面談履歴の一覧表示 【Must】

タレントごとの面談履歴を時系列で一覧表示できる。最新5件をダッシュボードに表示する。

### REQ-04: 前回記録の引き継ぎ表示 【Should】

新規面談作成画面に、前回面談の宿題・前回の主要トピックをサイドパネルに表示する。

### REQ-05: 面談テンプレート 【Should】

Will-Can-Must振り返り・スキル開発・キャリアプランのテンプレートから選択して面談メモを開始できる。

### REQ-06: 人材開発委員会への連携 【Should】

面談記録から「委員会に共有」フラグを立てると、タレントプロファイルの面談サマリー欄に反映される。

### REQ-07: エクスポート 【Could】

対象タレントの面談記録を PDF または Excel でエクスポートできる。

---

## 3. スコープ外（作らないこと）

- 面談のビデオ録画・音声録音機能
- タレント自身による面談メモの編集
- 外部カレンダー（Google Calendar / Outlook）との予定同期
- 360度評価（ピア評価）の記録

## 4. 受入基準

### REQ-01: 1on1記録の作成

**AC-01-01: 基本情報の入力と保存**
- Given: 上長がログイン済みで、配下タレントの1on1記録画面を開いている
- When: 実施日・形式（対面/オンライン）・各セクションのメモを入力して「保存」をクリックする
- Then: 記録が保存され、面談履歴一覧に追加される

**AC-01-02: 必須項目バリデーション**
- Given: 1on1記録作成フォームが表示されている
- When: 実施日を未入力のまま「保存」をクリックする
- Then: 「実施日は必須です」エラーが表示され、保存されない

**AC-01-03: 権限制御**
- Given: タレントAとタレントBが存在し、上長XはタレントAの直属上長である
- When: 上長XがタレントBの1on1記録を作成しようとする
- Then: タレントBの記録は作成できない（403エラー）。タレントAの記録のみ作成可能

### REQ-02: 宿題管理

**AC-02-01: 宿題の登録**
- Given: 1on1記録作成・編集画面が表示されている
- When: 宿題テキストを入力して「宿題を追加」をクリックする
- Then: 宿題一覧に追加され、ステータス「未完了」で表示される

**AC-02-02: 宿題の完了マーク**
- Given: 未完了の宿題が1件以上ある面談記録が存在する
- When: 次回面談作成画面を開く
- Then: 前回の未完了宿題が「前回の宿題」セクションに自動表示される

**AC-02-03: 宿題のステータス更新**
- Given: 面談記録に未完了の宿題が存在する
- When: 上長が宿題のチェックボックスをクリックして完了にする
- Then: ステータスが「完了」に変わり、完了日時が記録される

### REQ-03: 面談履歴一覧

**AC-03-01: 一覧表示**
- Given: タレントAの面談記録が3件存在する
- When: タレントAの面談履歴ページを開く
- Then: 3件が新しい順に一覧表示される（実施日・形式・メモ抜粋・宿題数）

**AC-03-02: ダッシュボード表示**
- Given: タレントに面談記録が存在する
- When: 上長のダッシュボードを開く
- Then: 配下タレントごとに最終面談日が表示される（30日以上前は警告色）

### REQ-04: 前回記録の引き継ぎ

**AC-04-01: サイドパネル表示**
- Given: タレントAに過去の面談記録が存在する
- When: 新規面談作成画面を開く
- Then: 前回面談の実施日・主要トピック・未完了宿題がサイドパネルに表示される

### REQ-05: 面談テンプレート

**AC-05-01: テンプレートを選択して面談メモを開始できる**
- Given: 上長が新規面談記録作成画面を開いている
- When: 「テンプレートを選択」ドロップダウンから「Will-Can-Must振り返り」を選択する
- Then: 選択したテンプレートの見出し構成がメモ入力欄にプリセットされる（テキストは空、見出しのみ挿入）

### REQ-06: 委員会連携

**AC-06-01: 共有フラグの設定**
- Given: 面談記録が保存されている
- When: 「委員会に共有」トグルをオンにして保存する
- Then: タレントプロファイルの「面談サマリー」に最大3件の面談タイトルと実施日が反映される

## 5. データモデル（概要）

```
OneOnOneMeeting {
  id: string (ULID)
  talentId: string → User.id
  managerId: string → User.id
  conductedAt: date
  format: enum { InPerson, Online, Hybrid }
  notes: {
    willTopics: string | null        # Will軸トピック
    canTopics: string | null         # Can軸トピック
    mustTopics: string | null        # Must軸トピック
    currentSituation: string | null  # 近況・体調
    freeText: string | null          # その他メモ
  }
  shareWithMdc: boolean (default: false)
  templateId: string | null
  createdAt: datetime
  updatedAt: datetime
}

MeetingActionItem {
  id: string (ULID)
  meetingId: string → OneOnOneMeeting.id
  description: string (max: 500)
  status: enum { Pending, Done }
  completedAt: datetime | null
  createdAt: datetime
}
```

## 6. APIエンドポイント（概要）

```
GET    /api/one-on-ones?talentId=&page=&limit=   → 面談履歴一覧（Manager/Senior/MDC）
POST   /api/one-on-ones                           → 面談記録作成（Manager）
GET    /api/one-on-ones/{id}                      → 面談記録詳細（Talent/Manager/MDC）
PUT    /api/one-on-ones/{id}                      → 面談記録更新（Manager）
DELETE /api/one-on-ones/{id}                      → 面談記録削除（Manager, 論理削除）

GET    /api/one-on-ones/{id}/action-items         → 宿題一覧
POST   /api/one-on-ones/{id}/action-items         → 宿題追加
PATCH  /api/action-items/{itemId}/status          → 宿題ステータス更新

GET    /api/talents/{talentId}/one-on-one-summary → 委員会用サマリー（MDC）
```

## 7. 非機能要件

| 項目 | 要件 |
|------|------|
| パフォーマンス | 面談一覧（50件）を2秒以内に返す |
| セキュリティ | 面談記録は担当上長・管理職・管理者（人事評価チーム）のみアクセス可能。タレント本人は閲覧のみ |
| データ保持 | 面談記録は考課期間終了後7年間保持する（Constitution.md セクション2.3: 労働基準法第109条準拠） |
| 監査ログ | 作成・更新・削除操作はすべてAuditLogに記録する |
